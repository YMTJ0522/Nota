# 09 附件与版本历史

这一页专门用来测**素材**和**版本快照**这两块，它们是「用久了才知道好不好」的功能。

## 附件库

侧栏点「附件库」，切到中间那一列。这一套测试里预置了一个文件：
工作区目录下的 `attachments/` 里有一张 Nota 的图标。

在附件库里可以：

- **导入**：右上角那颗上传图标，一次能选多个。图片、视频、压缩包（zip / rar / 7z / tar.gz）、
  文档（pdf / docx / xlsx / pptx / md / csv）、音频都收得进来，也能选「所有文件」。
  文件会被**复制**进 `attachments/`，不是引用原路径 —— 换机器、备份、拷走都不会丢。
- **插入**：卡片上的「插入」会在光标处写一行 `![名字](attachments/xxx)`；
  视频写的是 `<video src=...>` 标签（Markdown 没有原生视频语法）。
- **多选**：鼠标移到卡片上，左上角出现一个小方块，点它勾上。勾了之后可以
  「插入所选」「删除所选」，右键菜单里的动作也会对着**这一批**下手。
- **删除**：附件库的删除是直接从磁盘抹掉，没有回收站，所以要过一次确认。

## 版本历史

顶栏右上角，导出的旁边那本带箭头的书就是「版本历史」。

它是**按篇**存的：每一篇笔记在 `.nota-history/<相对路径>/` 下有自己的快照目录，
快照是普通的 `.md` 文件，出问题能用记事本打开看。

留快照的规则：

- **自动保存**：内容变了、并且距上一份快照超过 30 秒就会留一份。
  这样连打一段字只会留下一份，不会几百份中间态把历史淹掉。
- **手动保存**（`Ctrl+S`）、切笔记、关窗口：不设门槛，每次都留。
- 每篇最多保留最近 **40 份**，超了自动删最旧的。

### 怎么验证它真的在工作

1. 在这一行下面随便打几个字，等两秒（等自动保存落盘）。
2. 再打几个字，再等两秒。
3. 打开「版本历史」，左侧列表里应该出现对应的时间点。
4. 随便选一个，右边能看到那一刻的正文。
5. 点「恢复此版本」，内容会被**载入编辑器**（不会直接覆盖磁盘），
   顶栏的保存状态变脏，按 `Ctrl+S` 才真正写回。

这样设计是为了避免「点错了直接把现在的版本冲掉」——先载入、看一眼、再决定。

### 一个操作顺序上的小提示

如果你先打开了版本历史、又去改正文，历史列表不会自动刷新（它只在打开和换笔记时读一次）。
关掉再打开就是最新的。

## 导出

顶栏有四种导出，导出前会把笔记里的**相对媒体路径换成绝对路径**，
所以导出来的 HTML / Word / PDF 拿给别人，图片还在。

| 格式 | 特点 |
| --- | --- |
| Markdown | 就是源文件另存一份，最保真 |
| HTML | 单文件网页，样式内联，双击就能看 |
| Word | `.doc`，Word / WPS 直接打开 |
| PDF | 无头窗口打印，只打正文，不会把应用界面一起打进去 |
