# 06 图表与流程图

工具栏那颗**折线图图标**里是十一种现成模板。点一个就插一段写好的 Mermaid 代码，
预览里会真的画出来（不是代码框）。

下面每一种都真的渲染了一遍 —— 任何一块显示成红色错误或者原始代码，就是它坏了。

## 折线图

```mermaid
xychart-beta
  title "月度趋势"
  x-axis ["1月", "2月", "3月", "4月", "5月"]
  y-axis "数量" 0 --> 100
  line [28, 46, 39, 72, 88]
```

## 柱状图

```mermaid
xychart-beta
  title "各月销量"
  x-axis ["1月", "2月", "3月", "4月"]
  y-axis "销量" 0 --> 120
  bar [45, 78, 52, 96]
```

## 饼图

```mermaid
pie showData
  title 时间分配
  "写作" : 40
  "阅读" : 30
  "整理" : 30
```

## 流程图

```mermaid
flowchart LR
  A[开始] --> B{条件判断}
  B -- 是 --> C[执行]
  B -- 否 --> D[跳过]
  C --> E[结束]
  D --> E
```

## 时序图

```mermaid
sequenceDiagram
  participant U as 用户
  participant A as 应用
  U->>A: 打开笔记
  A-->>U: 返回内容
  U->>A: 保存修改
  A-->>U: 已保存
```

## 类图

```mermaid
classDiagram
  class Note {
    +String title
    +String body
    +save()
  }
  class Folder {
    +List~Note~ notes
  }
  Folder "1" --> "*" Note
```

## 状态图

```mermaid
stateDiagram-v2
  [*] --> Draft
  Draft --> Review : 提交
  Review --> Draft : 打回
  Review --> [*] : 通过
```

## 甘特图

```mermaid
gantt
  title 项目排期
  dateFormat YYYY-MM-DD
  section 设计
  原型   :a1, 2026-01-01, 7d
  评审   :a2, after a1, 2d
  section 开发
  编码   :a3, after a2, 14d
  联调   :a4, after a3, 5d
```

## Git 提交图

```mermaid

  checkout feature

  checkout main

```

## 写坏了会怎样

下面这个图是**故意写错的**（`flowchart` 后面跟了个不存在的方向）：

```mermaid
flowchart QQ
  A --> B
```

它不该让整篇预览白屏，只该在那一个块里变成红色的错误提示，别处照常。
