# 10 本版新增能力

这一页专门体检**这一轮新加的东西**。每一节都写了「怎么点」和「应该看到什么」，
照着走一遍，哪一项不对就立刻能看出来。

---

## 一、AI 编写：会话管理

侧栏或者中间那一列切到 **AI 编写**。

- [ ] 左上角那个会话下拉里，每一行右侧有个**垃圾桶**。点它 → 弹确认 → 删掉这个会话。
  （以前要切过去才能删，现在是就地删。）
- [ ] 删的是当前会话时，会自动落到下一个会话上，不会留一个空壳。
- [ ] 下拉底部「新对话」照旧。

### 新对话空态

新建（或删光）之后中间那块应该长这样：

- [ ] 一枚居中的图标 + 标题，不是干巴巴一行字。
- [ ] 下面几枚**快捷指令**卡片，点一下直接把指令填进输入框。
- [ ] 底部一行小字说明当前用的是哪个模型、走不走联网。

### 模型下拉只列已配置的

- [ ] 打开模型下拉，**只出现**你在设置里填过 API Key / 接口地址的那个服务商的模型。
- [ ] 没配置的整组不出现（不再摆一堆点不开的预设）。
- [ ] 接口探测失败时给一句说明，而不是静默空着。

## 二、AI 联网搜索

输入框左下角有一枚**地球图标**，就是联网开关。

- [ ] 点亮后发一条问句（比如「2026 年 Electron 最新稳定版是多少」）。
- [ ] 回答上方会出现一块「参考来源」，列出标题 + 链接，点链接走系统浏览器打开。
- [ ] 关掉开关再问同一句，那一块不再出现，回答只基于笔记和模型自身知识。
- [ ] 开关状态会被记住，重启还在。

> [!NOTE] 为什么要点开才生效
> 联网是**每轮**判定。开着的时候这一轮才去查，不是全局常驻。
> 查不到东西时照样回答，只是没有来源块 —— 不会假装查到了。

## 三、编辑区查找与替换

`Ctrl+F` 唤出查找条。

- [ ] 输入文字 → 立刻显示「第几个 / 共几个」。
- [ ] `Enter` 下一个，`Shift+Enter` 上一个，循环。
- [ ] 三个开关：**区分大小写** `Aa`、**全字匹配** `[]`、**正则** `.*`。
  正则写坏时输入框下方给一句红字提示，不会把整篇搞乱。
- [ ] 点 **替换** 展开第二行：替换一处 / 全部替换。
- [ ] 全部替换之后按 `Ctrl+Z` 能一次退回来（它改的是文档，不是草稿字符串）。
- [ ] `Esc` 关闭。

> [!WARNING] 中文输入时不该弹英文补全
> 在正文里用拼音打字，**不应该**弹出补全框（那会打断中文写作）。
> 想手动唤出补全按 `Alt+/`；代码块里打字会自动给候选。

## 四、粘贴 / 拖入图片

- [ ] 截一张图（`Win+Shift+S`），在编辑区里 `Ctrl+V` →
  图片自动存进工作区 `attachments/`，光标处插入一行 `![](attachments/xxx.png)`。
- [ ] 从资源管理器里**拖**一张图进编辑区 → 同样的效果，而且插在**松手的位置**，不是光标处。
- [ ] 一次拖多张 → 全部存进去、依次插入，末尾给一条提示。
- [ ] 粘贴**纯文本**时不会被这套逻辑劫持（只有真的带图片才拦）。

## 五、版本历史：并排对比

顶栏 → 版本历史。

- [ ] 左侧列表每个版本前面有个**复选框**，勾两个 → 顶部出现「对比」。
- [ ] 对比视图左右两栏，绿色是新增、红色是删除，行号对齐。
- [ ] 顶上给一句统计（加了几行、删了几行）。
- [ ] 退出对比回到单版本预览，「恢复此版本」照旧可用。

## 六、文件夹 / 笔记自定义图标

侧栏任意文件夹或笔记上**右键** → 「更换图标…」。

- [ ] 弹窗两个页签：**技术栈** / **表情**。
- [ ] 技术栈是真品牌图标（Python、Docker、HTML5、Java、Go、Rust、Vue、MySQL……），
  带品牌色，深色模式下太暗的会自动换成前景色，不会变成一块看不见的黑。
- [ ] 表情是**工作向**那一组：📌 待办、🐛 缺陷、🚀 上线、📊 数据、🔒 安全、🧪 实验……
  不是笑脸那一套。
- [ ] 选完侧栏立刻变，中间**卡片区的标题左边也显示同一枚**。
- [ ] 图标存在工作区 `.nota/icons.json`，键是**相对路径** —— 整个工作区换个盘符也不失效。
- [ ] 弹窗里有「恢复默认」。

## 七、表格圆角

预览区里的表格现在跟代码块一样是圆角的。

| 语言 | 用途 | 手感 |
| --- | --- | --- |
| Python | 数据处理 | 顺手 |
| TypeScript | 前端 | 严谨 |
| Rust | 系统 | 踏实 |

- [ ] 四角是圆的，边框不出现断口。
- [ ] 表头底色和代码块底色是同一套，深浅两色下都看得清。
- [ ] 表格超宽时允许横向滚动（此时边角会变直角 —— 这是浏览器的取舍，不是 bug）。

## 八、导出四种都齐了

顶栏导出下拉里现在四种都有：**Markdown / HTML / Word / PDF**。
（以前顶栏只有前两种，PDF 和 Word 得走右键菜单。）

- [ ] 四种导出来的排版一致：圆体、代码块圆角 + 语法高亮、表格圆角、引用块底色。
- [ ] 图片在 HTML / Word / PDF 里都在（导出前把相对路径换成了绝对路径）。
- [ ] 中文不乱码（HTML 里写死了 `<meta charset="utf-8">`）。
- [ ] Word 用 WPS / Word 打开能直接编辑，不弹兼容提示。
- [ ] PDF 只打正文，不把应用界面一起打进去。

## 九、关于「工作区 Git 同步」

这个功能**没有做**，理由写在下面，免得后面又想起来问。

Git 同步不是「回收站」，它不管删没删得回来。它做的是：

1. 把你整个笔记文件夹变成一个 Git 仓库；
2. 每次保存自动 `commit`；
3. 你可以 `push` 到远端（GitHub / Gitee），换台机器 `pull` 回来。

它解决的其实是**另一件事**：跨设备 + 任意时间点的回溯。
而任意时间点回溯这一格，版本历史已经填上了（见第五节）。

没做的原因是它需要 Git 环境、要处理冲突、要有远端凭据 —— 三样加起来
比它带来的好处重得多，而且一旦冲突处理不好会**弄丢笔记**。
真要跨设备同步，现阶段更稳的办法是：把笔记文件夹丢进 OneDrive / 坚果云 / 百度网盘同步盘。

如果后面确实需要，再说。
