# 05 代码块与表格

## 怎么选语言

在编辑器里打出三个反引号再回车，会得到一个空的代码块，
**右上角会出现一个小标签**，点它才弹语言列表（不点它就一直是个空块）。

顺序是「先把框写出来，再决定它是什么语言」——比起一上来就逼你选，
这样不打断思路。带语言标签的代码块在预览里是有高亮的。

## 高亮示例

```python
def save_note(path: str, content: str) -> None:
    """把正文写回磁盘。"""
    with open(path, "w", encoding="utf-8") as f:
        f.write(content)
    print(f"saved {len(content)} chars → {path}")
```

```javascript
export function baseNameOf(path) {
  const parts = path.split(/[\\/]/)
  return (parts[parts.length - 1] ?? '').replace(/\.md$/i, '') || '未命名笔记'
}
```

## 高级代码块

工具栏「代码与图表 → 高级代码块」会插一个带标题和行号的块：

```js title="保存流程" line-numbers {2}
const dirty = doc !== saved
if (!dirty) return          // 这一行会被标出来
await api.write(path, doc)
```

- `title="..."` 给这块加一个标题
- `line-numbers` 让左边显示行号
- `{2}` 高亮第 2 行

## 表格

工具栏的表格按钮弹的是**九宫格**：鼠标划过去会高亮 行 × 列 的区域，
右上角实时显示 `3 × 4`，点下去就按这个尺寸生成。

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 苹果 | 🍎 | 3.50 |
| 香蕉 | 🍌 | 12.00 |
| 一长串比较长的中文内容，用来验证单元格能不能正确换行 | 短 | 100.00 |

单元格里也能放行内格式：**粗**、*斜*、`代码`、[链接](https://example.com)。

## 该注意的地方

- 表格第一行是表头，第二行是 `---` 分隔行，缺一行就不成表
- 单元格里想打竖线要写 `\|`，否则会被当成列分隔
- 代码块里的 `|` 和 `#` 都不会被表格、标题的语法抢走
