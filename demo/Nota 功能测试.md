# Nota 功能测试

这一份是**给功能做体检用的**，不是教程。每个文件对应工具栏或侧栏里的一块能力，
打开它、照着上面写的点一遍，就知道那一块还好不好用。

> [!TIP] 怎么用这一套
> 用侧栏底部的设置按钮 → 通用 → 「打开目录」，选到 **demo** 这一层。
> 侧栏会出现「入门 / 进阶」两个文件夹，中间那一栏是笔记列表。
> 想恢复原样就把这个文件夹整个删掉重来 —— 里面全是测试内容，没有你的真实笔记。

## 侧栏与界面

- [ ] 侧栏四个导航：所有笔记 / 最近编辑 / 收藏 / 未归类 —— 点当前那个会回到「所有笔记」
- [ ] 文件夹行**右键**：新建笔记、新建子文件夹、重命名、复制路径、在系统打开、删除文件夹
- [ ] 标签行**右键**：只看这个标签、复制标签名、重命名标签、删除标签
- [ ] 标签这一块的两个加号：清除筛选、新建标签（写在当前这篇的 frontmatter 里）
- [ ] 底部：工作区名字 + 设置

## 中间那一列

- [ ] 三个页签：笔记 / 大纲 / 引用
- [ ] 笔记列表右上角的两个按钮：导入笔记、新建笔记
- [ ] 卡片右键：打开、收藏、重命名、归类、复制路径、在系统打开、四种导出、删除
- [ ] 卡片上的星：直接收藏，不用开右键
- [ ] 卡片上的垃圾桶：点一下变「确认删除」，4 秒后自己退回去
- [ ] 附件库：勾选方块多选、右键菜单、导入、插入、删除
- [ ] 回收站：多选、恢复所选、彻底删除所选、清空（都要过确认弹窗）
- [ ] AI 编写：会话管理、上下文开关、快捷指令
